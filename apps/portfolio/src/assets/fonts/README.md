# Portfolio fonts

These are the same fonts previously loaded from external stylesheets.
They are served locally to keep page rendering independent of font CDN availability.

- `arcade-interlaced.woff`: Arcade Interlaced, copyright 1997-2003 Yuji Adachi, copied unchanged from the [existing CDN source](https://fonts.cdnfonts.com/s/6068/ARCADE_I.woff).
- `press-start-2p.ttf`: Press Start 2P by CodeMan38, copied unchanged from the [existing Google Fonts source](https://fonts.gstatic.com/s/pressstart2p/v16/e3t4euO8T-267oIAQAu6jDQyK0nS.ttf).
  Its SIL Open Font License is preserved in `press-start-2p-OFL.txt` from the [Google Fonts repository](https://github.com/google/fonts/blob/main/ofl/pressstart2p/OFL.txt).
